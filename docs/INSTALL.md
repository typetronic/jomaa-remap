# Installation Guide

## Step 1 — Download
Download JomaaRemap-1.0.dmg from Releases.

## Step 2 — Install
1. Double-click the DMG
2. Drag JomaaRemap.app onto Applications shortcut
3. Eject the DMG

## Step 3 — First launch
1. Open Applications in Finder
2. Right-click JomaaRemap → Open
3. Click Open again
4. Or in Terminal: xattr -dr com.apple.quarantine /Applications/JomaaRemap.app

## Step 4 — Grant Input Monitoring
1. macOS shows a permission dialog
2. Click Open System Settings
3. Enable toggle for JomaaRemap
4. Restart the app

## Step 5 — Verify
Connect your keyboard, press a key.

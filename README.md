# JomaaRemap

Community-built macOS driver for JOMAA keyboards.

## Features
- Key remapping, macros, layers
- Native SwiftUI interface
- Local only, no telemetry
- Signed DMG

## Requirements
- macOS 13+
- Apple Silicon or Intel
- Input Monitoring permission

## Installation
1. Download JomaaRemap-1.0.dmg from Releases
2. Drag to Applications
3. Right-click → Open (first launch)
4. Grant Input Monitoring
